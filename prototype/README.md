# LLM Switch 原型（Ant Design）

按"默认即正确、用户零思考"的原则重画的管理界面原型。独立于现有 Go 实现，使用模拟数据，可直接运行查看。

## 运行

```powershell
npm install
npm run dev        # 开发：http://localhost:5199
npm run build      # 构建静态原型
npm run preview    # 预览构建产物：http://localhost:5199
```

技术栈：Vite 5 + React 18 + Ant Design 5 + @ant-design/icons，中文 locale。

## 页面结构

| 页面 | 内容 |
|---|---|
| 总览 | 代理状态、供应商/模型数量、Codex 接入状态、三步接入进度、最近调用 |
| 供应商与模型 | 供应商列表 + 模型表格；添加供应商 → 自动测试 → 自动拉取模型 → 勾选导入 |
| 接入 Codex | 一键接入 / 已接入状态、默认模型与请求地址、自动同步开关、高级手动编辑 |
| 设置 | 开机启动、启动行为、代理端口、日志、配置目录，全部有推荐默认值 |

## "把用户当猪"的交互设计

1. **能默认就默认**
   - 供应商：选预设后名称、接口地址、协议全部自动填好，只需要粘贴 API Key。
   - 模型：保存供应商后自动测试连接、自动拉取模型列表，并默认全选，一键添加。
   - 模型元数据：上下文窗口、推理档位由元数据自动补全，界面打「自动」标签，可随时改。
   - Codex：默认模型取第一个可用模型，请求地址固定本机代理，自动同步默认开启。
   - 设置：开机启动、启动打开控制台默认开启；端口、日志级别、保留天数都有推荐值。
2. **危险操作有护栏**：删除供应商/模型有确认并说明影响；断开 Codex 只移除自己写入的配置。
3. **状态一眼可见**：顶栏常驻代理状态与默认模型；总览用三步进度引导首次接入。
4. **高级能力折叠**：手动编辑 config.toml / auth.json / 模型清单收进「高级」，并注明通常不需要。
5. **可恢复**：写入前校验、失败不影响原配置；恢复默认设置不删数据。
