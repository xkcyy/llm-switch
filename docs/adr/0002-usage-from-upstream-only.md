# 用量只采信上游上报，不估算

统计用量（调用次数与 token 数）时，代理只读取上游响应里的 `usage`；上游未上报时记为「无用量」，token 记 0，不按字符数或其它启发式估算。估出的数字无法与供应商账单对照，还会让按模型、按供应商的横向比较失真；宁可缺失也不失真。

## Considered Options

- **字符估算**：把请求与响应文本按比例折算 token。舍弃：不可对账，且对推理型与高缓存命中场景偏差极大。
- **只统计非流式**：流式是 Codex 的常态调用路径，等于放弃统计。

## Consequences

- 为使缺失尽量少，chat 直通在客户端未指定时注入 `stream_options.include_usage`——KmAiModelHub 的 chat 流式不注入就不回 usage；转换路径本就注入。
- 上游 usage 字段名不统一（`input_tokens` / `prompt_tokens`，缓存字段位置不一），解析需做字段名归一化。
- 无用量调用单列计数，界面显式标注，不与有用量调用混算。
